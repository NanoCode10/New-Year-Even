# Prompt: Crear un juego de navegador “Neon Dash”

Crea un juego de navegador pequeño pero adictivo usando solo **HTML, CSS y JavaScript vanilla**.

## Idea del juego

- Un juego arcade de un solo botón llamado **“Neon Dash”**.
- El jugador controla un cuadrado brillante que salta o hace dash para evitar obstáculos entrantes.
- El juego debe ser fácil de entender en 5 segundos, pero difícil de dominar.

## Requisitos

- Crear todos los archivos necesarios.
- No usar dependencias externas ni pasos de compilación.
- Hacer que se vea visualmente pulido, con un estilo oscuro y neón.
- Incluir puntaje, mejor puntaje usando `localStorage`, dificultad progresiva, flujo de reinicio y una pantalla breve de instrucciones.
- Agregar pequeños detalles que lo hagan sentirse más dinámico y satisfactorio: partículas, sacudida de pantalla, interruptor de sonido usando Web Audio simple si es posible, y feedback satisfactorio al sumar puntos.
- Mantener el código legible y separar HTML, CSS y JS en archivos distintos.
- Agregar un `package.json` con un script de desarrollo para servir el juego localmente.
- Después de crearlo, explicar cómo ejecutarlo localmente con `pnpm`.

## Importante

- No sobre-ingenierizarlo.
- Priorizar que sea jugable y divertido antes que tener una arquitectura perfecta.
